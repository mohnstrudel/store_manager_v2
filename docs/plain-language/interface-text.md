# Interface text

Use these rules for labels, buttons, links, help text, empty states, confirmations, errors, and status messages.

- Use direct verbs and name the action or result.
- Prefer specific labels such as `Save sale` over context-dependent labels such as `Submit`.
- Make errors useful. Say what happened and what the person can do next.
- Report pending, completed, and failed states truthfully. Do not imply success before an action finishes.
- For destructive actions, name the affected item and the consequence. Do not rely on a vague question such as `Are you sure?`
- Use one consistent term for each business concept. Do not introduce synonyms for variety.
- Use few links, and make each one descriptive. The link text should tell the person where it leads or what it does.
